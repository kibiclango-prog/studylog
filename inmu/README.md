# InmuLM

淫夢語録だけでしゃべる、かるめの言語モデル。依存なし・API キー不要・ブラウザだけで動きます。

- `index.html` … チャット画面（`inmu/index.html` をブラウザで開くだけ）
- `model.js` … モデル本体（ブラウザ / Node 両対応）

## しくみ

ふつうの LLM は「文字や単語」をトークンにしますが、InmuLM は **語録 1 つを 1 トークン** にしています。
語彙が語録しかないので、何を入力しても語録しか出てきません。

1. 入力から意図（あいさつ・質問・ほめ・疲れ・お腹すいた…）を正規表現で推定
2. 各語録をスコアリング（意図タグの一致 + 文字 bigram の重なり − 繰り返しペナルティ）
3. 温度つきソフトマックスで 1 語録サンプリング
4. 語録どうしの遷移（`next`）で最大 3 語録までつなげる

温度を上げるとランダムで饒舌に、下げると素直で無口になります。

## Node で使う

```js
const InmuLM = require('./model.js');
const lm = new InmuLM({ temperature: 0.7, seed: 1 });
lm.reply('疲れた〜'); // => 'ぬわああああん疲れたもおおおおん'
```

語録を増やしたいときは `model.js` の `PHRASES` に `{ id, t, tags, next }` を足すだけです。
