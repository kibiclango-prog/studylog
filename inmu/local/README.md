# InmuLM ローカル版（8B）

自分の PC 上の 8B モデルに、淫夢語録だけで会話させます。インターネットも API キーも不要（最初のモデルのダウンロードだけネットが要ります）。

## 必要なもの

- メモリ 16GB 以上（GPU なしでも動く。NVIDIA の VRAM 8GB 以上か Apple Silicon なら快適）
- ストレージの空き 10GB 程度
- Python 3.8 以上（追加ライブラリ不要）

## 手順

1. **Ollama を入れる**: https://ollama.com からインストーラを落として入れる（Windows / Mac / Linux）
2. **8B モデルを落とす**（約 5GB）
   ```
   ollama pull qwen3:8b
   ```
3. **起動**（Ollama アプリが動いていれば OK。動いていなければ `ollama serve`）
   ```
   python3 chat.py
   ```
   Windows では `python chat.py`。別のモデルを試すときは `--model モデル名`。

## しくみ

- `goroku.json` に語録と「意味・使いどころ」を書いておき、それをプロンプトでモデルに教える
- モデルは返事として語録の **ID を 1〜3 個選ぶだけ**
- その ID は JSON スキーマの `enum` で縛っている（Ollama の構造化出力）ので、語録以外の文字列は出せない
- 会話履歴も渡すので、流れを読んだ返し（「寝てたでしょ」→「ないです」→「絶対寝てた」→「嘘つけ絶対見てたゾ」）ができる

語録を増やすときは `goroku.json` に `{"id", "t"（語録）, "m"（意味）}` を足すだけ。`m` をちゃんと書くほど選び方が賢くなります。
